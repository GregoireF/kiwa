# Support

- **Something does not work:** read [Troubleshooting](docs/how-to/troubleshoot.md), then open a
  [bug report](https://github.com/GregoireF/kiwa/issues/new/choose) with `kw --version` and
  `kw info <project> --json`.
- **A question:** [Discussions](https://github.com/GregoireF/kiwa/discussions).
- **A security issue:** privately, as [SECURITY.md](SECURITY.md) explains. Never in a public issue.
